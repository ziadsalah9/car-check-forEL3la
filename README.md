# ندي مطاوع | دليل السيارات

تطبيق React متجاوب للبحث عن السيارات والشركات المصنّعة، وعرض جنسية الشركة وعلم الدولة وصورة الموديل ومعلوماته الأساسية.

## المتطلبات
- Node.js إصدار 20 أو أحدث (يوصى بإصدار LTS).
- اتصال إنترنت لتحميل صور السيارات والخطوط من مصادر خارجية.

## التشغيل على Windows
1. فك ضغط ملف المشروع.
2. افتح مجلد `car-encyclopedia`.
3. افتح Terminal أو PowerShell داخل المجلد.
4. نفّذ:

```bash
npm install
npm run dev
```

5. افتح الرابط الذي يظهر في الطرفية، غالبًا `http://localhost:5173`.

## إنشاء نسخة إنتاجية
```bash
npm run build
npm run preview
```
سيتم إنشاء ملفات النشر داخل مجلد `dist`.

## الوظائف الحالية
- البحث بالاسم العربي أو الإنجليزي، أو اسم الشركة، أو بلد المنشأ.
- فلترة النتائج حسب الدولة.
- عرض صورة السيارة واسم الموديل واسم الشركة وجنسيتها وعلمها.
- نافذة تفاصيل للموديل والشركة مع الموديلات الأخرى الموجودة في الدليل.
- قائمة مفضلة محلية أثناء تشغيل الصفحة.
- تصميم متجاوب للكمبيوتر والموبايل.

## أين أضيف سيارات أو شركات؟
افتح `src/data.js`.
- أضف الشركات داخل مصفوفة `brands`.
- أضف الموديلات داخل مصفوفة `cars`.
- قيمة `brandId` في السيارة يجب أن تطابق `id` شركة موجودة.
- `image` رابط صورة مباشر. استخدم صورًا لديك حق استخدامها أو صورًا من مصدر يسمح بإعادة الاستخدام.

## ملاحظات مهمة
- هذه نسخة أولية ببيانات ثابتة محلية، وليست قاعدة بيانات رسمية أو شاملة لكل السيارات.
- بعض صور العرض تأتي من روابط Unsplash، لذا يلزم اتصال إنترنت وقد تتغير الصور أو لا تطابق الموديل بدقة. قبل النشر التجاري، استبدلها بصور موثوقة ومرخصة.
- بلد الشركة وجنسيتها يختلفان عن بلد تجميع أو تصنيع سيارة محددة. أضف بلد التصنيع على مستوى الموديل/السنة إذا احتجت دقة أكبر.
- يمكن في مرحلة لاحقة إضافة Backend وقاعدة بيانات ولوحة تحكم ومصدر بيانات خارجي.


## تحديثات الاسم والبحث
- اسم الواجهة أصبح **ندي مطاوع**.
- البحث يقبل الاسم العربي والإنجليزي، ويطبع اختلافات عربية شائعة مثل (أ/إ/ا) والتشكيل قبل المطابقة.
